## Engineering Principles

Security before convenience.

Privacy by Design.

Zero Trust.

Least Privilege.

Immutable Evidence.

Clean Architecture.

SOLID.

DDD.

CQRS where appropriate.

Event Driven Architecture.

Every service independently deployable.

--------------------------------------------------

## Security Rules

Evidence is encrypted before leaving the endpoint.

Keys never leave Eride Vault.

No plaintext evidence at rest.

Temporary plaintext only exists during authorised viewing.

Evidence export is different from evidence viewing.

Every privileged action is audited.

Every API authenticated.

Every request authorised.
